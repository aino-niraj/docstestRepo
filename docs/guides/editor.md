# Documentation editor

The editor supports common Markdown content including headings, emphasis, links, code blocks, tables, and images.

## Recommended workflow

1. Open a page in Edit mode.
2. Make a small content change.
3. Save the page.
4. Open Preview in a new tab.
5. Confirm navigation and formatting.

## Example configuration

```json
{
  "branch": "main",
  "sourceFolder": "docs",
  "mountPath": "test-docs"
}
```

See [repository synchronization](repository-sync.md) for conflict behavior.
