# Installation and connection

Connect this repository to an AppOps Docs project using the following values:

| Setting | Value |
| --- | --- |
| Branch | `main` |
| Source folder | `docs` |
| Mounted path | `test-docs` |

After connecting, select **Sync**. The pages under `docs/` should appear below the mounted path in the documentation tree.

## Verification

- The root page renders as the section index.
- Nested folders are expandable.
- Relative links open inside the preview.
- A second sync reports unchanged pages.

Continue to [your first project](first-project.md).
